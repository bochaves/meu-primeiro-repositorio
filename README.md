🐾 Focinho Urbano
Sobre o projeto
Focinho Urbano é um projeto desenvolvido com o objetivo de facilitar a gestão de uma creche pet.

🎯 Objetivo
A proposta é desenvolver uma aplicação que contribua para uma gestão cadastro de cliente, gestão de agenda e controle financeiro.

🛠️ Tecnologias utilizadas
Java
Git
GitHub

💻 Desenvolvimento
Projeto desenvolvido como parte do meu aprendizado em programação, colocando em prática conceitos da linguagem Java e lógica de programação.
